# نشر حزمة عناوين البحث وصفحات الوجهات — wosol.net فقط

التاريخ: 2026-11-28 (Asia/Riyadh). الحالة: منشور ومتحقق منه عبر HTTPS.

## النطاق والنتيجة
- موافقة المستخدم الصريحة على النشر؛ لم تُمس الحملات أو wosoltransportation.com، ولم تُرسل نماذج.
- مقارنة 36 صفحة قائمة وsitemap.xml وrobots.txt قبل النشر: 38 موردًا بلا اختلاف عن أساس الدمج.
- نشر 60 صفحة HTML بالعربية والإنجليزية، منها صفحات 17 وجهة (34 صفحة)، مع الإبقاء على المقدمة «حلول نقل متكاملة تُسهّل أعمالك» واللون والصورة وLinkedIn.
- خريطة الموقع تضم 62 رابطًا، منها 24 صفحة جديدة لـ12 وجهة.

## إصلاح لازم أثناء النشر
كانت قواعد المسارات العربية النظيفة في .htaccess محصورة في المدن الخمس القديمة؛ ظهرت صفحة نيوم دون الامتداد 404 بينما ملفها ونسختها الإنجليزية يعملان. أُضيفت أسماء الوجهات الـ12 إلى قوائم المسارات الثلاث القائمة فقط، مع الحفاظ على بقية القواعد والتحويلات والإلغاءات القديمة. بعد الحفظ نجحت جميع المسارات العامة.

## التحقق
- جلب 60 صفحة وخريطة الموقع من الروابط العامة: 61 استجابة HTTP 200، ومطابقة كاملة لنصوص ملفات الحزمة، دون noindex.
- عناوين مخصصة باللغتين، canonical على www.wosol.net وروابط لغات مقابلة.
- فحص الجوال بعرض 390: جميع الصفحات الستين دون تجاوز أفقي أو اقتطاع h1/h2/فقرات main وفق قياس DOM.
- مراجعة بصرية للصفحة الرئيسية AR/EN وصفحة المدينة الاقتصادية الإنجليزية على الكمبيوتر؛ التصميم والعناوين متناسقة. المراجعة الشاملة لحزمة الدمج على الكمبيوتر والجوال تمت أيضًا قبل النشر.
- فحص الكاش العادي ومع معامل تحقق للرئيسية باللغتين ونيوم العربية وأمالا الإنجليزية: مطابقة للمحتوى الجديد. استجابات CDN كانت BYPASS؛ لم يلزم تفريغ شامل.
- لم تُغيّر ملفات JS أو CSS أو النماذج؛ بقي تسجيل الطالبات كما هو.

## المتبقي
- متابعة قراءة خريطة الموقع والفهرسة الفعلية والعناوين في Search Console وBing لاحقًا؛ سلامة الفهرسة التقنية ليست إثباتًا لظهور الصفحات أو ترتيبها.
- لا طلبات فهرسة جديدة أو مكررة ضمن هذا التنفيذ.
- تقارير prepared السابقة تمثل مرحلة سابقة؛ هذا التقرير هو نتيجة النشر الأحدث.
