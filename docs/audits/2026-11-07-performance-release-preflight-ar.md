# تجهيز تحسين الأداء للنشر — غير منشور

طلب الاستكمال لم يُعامل كاعتماد صريح لتجاوز قيد المعاينة فقط. أُعدت حزمة إنتاج منفصلة، دون رفعها للاستضافة أو تغيير الموقع الرسمي أو المعاينة المنشورة.

## المنجز
- إعداد 36 صفحة من مصادر الإنتاج الأصلية، مع استبدال مرجع CSS والصورة1999px وتعديل fallback لصورة preload فقط.
- نسخ الموردين المحسنين المطابقين ببصمة اسم الملف لموردي المعاينة المقاسة. لا إعادة ترميز أو تغيير بصري جديد.
- فحص1415مرجعًا محليًا، وبقاءindex,follow وغيابnoindex وحارس منع الإرسال وأكواد قياس الاختبار من حزمة الإنتاج.
- مقارنة المحتوى الأصلي والناتج بعد استثناء الاستبدالات المحددة؛ لم تتغير النصوص أو الروابط أو النماذج أو البيانات المنظمة أو إعدادات القياس.
- نجاحcheck-approved-release وcheck-zoho-handoff؛ الأخير محاكاة بلا طلبات شبكة أو إرسال نماذج.
- إعدادupload.zip وrollback.zip في مجلدwosol-performance-release-20261107 المجاور للمستودع. ملفات الرجوع هي نسخة مصادر المستودع قبل التعديل، وليست نسخة احتياطية مؤكدة من الخادم الحالي.

## قبل النشر وبعده
1. اعتماد المالك نشر تحسين الأداء بعد مراجعة المعاينة. لا تُرفع حزمة المعاينة المحتوية علىnoindex.
2. مقارنة بصمات الصفحات الحالية على الخادم معbefore في بيان الحزمة؛ عند اختلافها تُراجع التعديلات الأحدث ولا تُستبدل تلقائيًا. أخذ نسخة احتياطية من الخادم قبل النشر.
3. رفع CSS والصورة الجديدين أولًا، والتحقق منهما، ثم الصفحات. إبقاء الموارد القديمة لسلامة الصفحات المخزنة بالكاش وإتاحة الرجوع.
4. تحديث كاش الصفحات، ثم مقارنة البصمات العامة معafter وفحص العربية والإنجليزية والجوال وروابط الخدمات والتحويل إلىZoho دون إرسال.
5. إعادة قياسPSI وتسجيل ظروفه، ثم متابعةLCP الميداني؛ النتائج المحلية ليست ضمانًا لنتيجة الإنتاج.

لا رفع رسمي ولا تغييرDNS أو طلب فهرسة أو تشغيل إعلانات في هذه الجولة. المتبقي اعتماد النشر فقط لهذه الحزمة، ثم تنفيذ خطوات التحقق أعلاه.
