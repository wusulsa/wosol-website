# معالجة كاش رابط عرض السعر — 19 أكتوبر 2026

دخلنا Supersonic باستخدام جلسة Namecheap المتاحة، ونفذنا Purge all ثم Clear Cache لموقع wosol.net. لم تتغير مدة التخزين أو استثناءاته أو إعداد Ignore Query String أو الحماية أو الشهادة أو DNS.

التحقق: طلبات GET العامة للرابطين https://www.wosol.net/?contactTab=quote وhttps://www.wosol.net/en/?contactTab=quote نجحت وأظهرت email-submit.v7.js وحالة BYPASS من نقطة FRA. أول فتح في جلسة المتصفح احتفظ بالمحتوى القديم؛ إعادة تحميل كل رابط أظهرت i18n.v14.js وemail-submit.v7.js. لا معاملات جديدة لتجاوز الكاش. إثبات المتصفح وGET متوافقان بعد إعادة التحميل. لا ادعاء فحص كل نقاط CDN أو كل الأجهزة.
