# فحص الوصول العام وCDN — 27 أكتوبر 2026

## النتيجة الحالية
لم يثبت اكتمال إصلاح الوصول من بيئة الفحص. نجح فحص TLS الخارجي للنطاقين على عنوان CDN نفسه، بينما تستمر إعادة تعيين الاتصال محليًا قبل استلام الشهادة. لذلك لا يصح وصف الحالة بانتهاء الشهادة أو انقطاع عالمي، ولا يصح إغلاق بند التحقق من التحويلات العامة.

## ما نُفّذ
- الدخول إلى Supersonic عبر جلسة Namecheap القائمة؛ الخدمة تعرض ONLINE والشهادة CUSTOM SSL / PROTECTED.
- تأكيد عنوان المصدر HTTPS 198.187.29.14 وعدم تغيير البروتوكول أو DNS أو البريد أو الشهادة.
- تغيير Query String Control من Ignore إلى Custom بمعامل product، ثم Purge all. أُعيد تحميل اللوحة وثبت حفظ المعامل. الهدف فصل كاش الروابط القديمة عن الرئيسية؛ الأثر الفعلي على HTTP العام لم يُثبت من اتصالنا بعد.
- التواصل مع دعم Namecheap، المختص Andrii N.، وتقديم خطوات تكرار العطل ومرجع تحديث الشهادة السابق NC-ZSZ-6185. طُلب فحص التحويلات الثلاثة وتصعيد تشخيص الاتصال إلى فريق CDN/الشبكة.

## الأدلة
| الفحص | النتيجة |
|---|---|
| DNS المحلي و1.1.1.1 و8.8.8.8 | عنوان CDN هو 162.0.212.2 |
| HTTP العام | 302 إلى HTTPS |
| HTTPS من اتصالنا | curl (35): Connection was reset؛ المتصفح ERR_TIMED_OUT |
| TLS 1.2 و1.3 محليًا | كلاهما تعذر عبر CDN |
| TLS على الخادم مع التحقق من الثقة واسم النطاق | ناجح للنطاقين؛ انتهاء 3 مايو 2027، 21:12:15 UTC |
| decoder.link للنطاقين | TLS 1.3 ناجح، اسم النطاق وسلسلة الثقة صحيحان على 162.0.212.2 |
| شهادة CDN المقدمة للفاحص الخارجي | SSL.com، الرقم 528107da1560468df42c03fe7898a046، انتهاء 3 مايو 2027 |
| فحص الإلغاء OCSP الخارجي | تعذر الحصول على الرد؛ لا يُفسر بأنه نجاح أو إلغاء |
| إفادة الدعم | الموقع يفتح لديهم على عنوان CDN نفسه؛ ليست إثباتًا لنجاح اتصالنا |

فحص الشهادة الخارجي لا يثبت وحده رموز تحويلات HTTP أو سلامة جميع المواقع الجغرافية والأجهزة. طُلب من المالك اختبار الرابط من بيانات الجوال لاستبعاد شبكة Wi-Fi؛ لم ترد نتيجة عند كتابة هذا التحديث.

## المتبقي
1. تحديد سبب reset من الاتصال المتأثر والتحقق من عدم وجود حظر أو مشكلة مسار إقليمي مع الدعم، دون تعطيل الحماية.
2. إثبات 301 ثم 200 للروابط العامة product=edu11 وedu3 وedu33؛ نجاحها على الخادم موثق في التقرير السابق فقط.
3. التحقق من عدم مشاركة كاش المعاملات المركبة مع التحويلات الدقيقة. سُئل الدعم عن استثناء الجذر / وحده من الكاش دون استثناء جميع الموارد؛ لا يُطبّق استثناء واسع بالتخمين.
4. مراجعة العربية والإنجليزية عبر المسار العام بعد نجاح الاتصال.
