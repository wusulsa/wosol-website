# إصلاح نوع العميل ومراجعة اعتمادية الطلبات
التاريخ: 21 أكتوبر 2026.

## المنجز
- نشر نص الاختيار الإنجليزي «Select type» مع بقاء عنوان «Customer type»، وخياري Individual وOrganisation.
- كشف الفحص الأول اقتطاع آخر حرف من Select customer type عند 320px؛ اختُصرت العبارة وأعيد النشر والفحص.
- فحص بصري للإنتاج: العبارة وOrganisation كاملان عند 320px، وIndividual كامل عند 390px. لا تجاوز أفقي (305/320 و375/390).
- قيم الربط individual / organisation لم تتغير؛ النصوص العربية وتسجيل الطالبات ومسارات Zoho لم تتغير.
- بناء 36 صفحة، 1415 مرجعًا، 17 أصلًا، وخريطة 38 رابطًا: صفر أخطاء.
- تحقق الإنتاج: 53/53 ملفًا مطابقًا للمصدر. لم يلزم تفريغ CDN بعد ظهور الأصل ذي الاسم الجديد.
- اختبار قفل الانتقال المحلي: خمس حالات ناجحة دون شبكة، تشمل منع الضغط المكرر واستعادة BFCache والتعافي من الفشل قبل الانتقال.
- لم تُرسل نماذج أو رسائل دعم، ولم تُشغل إعلانات.

## البريد والتكرار: حدود ما ثبت
سجل Email Audit مفعل للنموذجين وفق المراجعة السابقة. مراجعة نموذج عرض السعر أظهرت عدم وجود معلومات تدقيق بريد متاحة؛ هذا لا يثبت التسليم ولا ينفي الفشل.
لم يظهر خيار مثبت لتنبيه فشل تسليم البريد في الإعدادات التي فُحصت. تنبيه فشل التكامل ليس تنبيه ارتداد البريد.
أجّل المالك مراسلة الدعم صراحةً. البديل المقترح حاليًا مراجعة الإدارة لسجل البريد يوميًا؛ لم تُنشأ أتمتة أو مهمة مجدولة.
خاصية No Duplicates للبريد غير مفعلة ولم نفعّلها: تقييد البريد أو الهاتف قد يمنع طلبات لاحقة مشروعة للعميل.
قفل الإرسال في المتصفح منشور، لكنه لا يمنع التكرار عبر أجهزة مختلفة أو الطلب المباشر إلى Zoho. منع التكرار الخادمي بمعرف مستقل لكل طلب ما زال غير منفذ ويحتاج تصميمًا واختبارًا مضبوطًا قبل اعتماده.

## المتبقي وما يحتاج اعتمادًا
| البند | الحالة / المطلوب |
|---|---|
| تنبيه فشل البريد تلقائيًا | مؤجل؛ مراسلة الدعم مؤجلة بطلب المالك. يلزم إثبات قناة مدعومة قبل ربطها |
| منع تكرار الطلب على الخادم | مفتوح؛ لا يُغلق باختبار قفل المتصفح. يلزم اختبار مصرح به لاحقًا |
| مدة الاحتفاظ بالطلبات والمرفقات | تحتاج اعتماد المالك؛ لا حذف أو احتفاظ آلي مطبق |
| تنظيف سجلات الاختبار المتبقية | يتطلب تحديد السجلات واعتماد الحذف المناسب |
| Google وBing وظهور الخدمات والأيقونة | تُراجع وفق سجل البحث الأخير؛ لا فحص جديد أو تكرار طلبات في هذه الجولة |
| توثيق الشهادات ونسب الأداء | يحتاج مستندات المالك ومنهجية الأرقام |
