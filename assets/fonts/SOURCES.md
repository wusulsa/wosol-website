# Existing website fonts, hosted locally

Downloaded 2026-10-14 from Google Fonts for the existing Tajawal (400, 500, 700, 800) and Inter (400, 500, 600, 700) families. CSS preserves `font-display: swap`.

Source: https://fonts.googleapis.com/css2?family=Tajawal:wght@400;500;700;800&family=Inter:wght@400;500;600;700&display=swap

Licences: `Tajawal-OFL.txt` and `Inter-OFL.txt`, from the respective `ofl` directories of https://github.com/google/fonts. Fonts are unmodified.
